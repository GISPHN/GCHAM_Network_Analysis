G-CHAM Network Analysis 0.4.11

概要
既存の道路ラインと起点・目的地ポイントから、最短距離ルートを作成し、選択速度から所要時間の参考値を算出します。時間最短ルートではありません。解析結果はCSVとGeoPackageへ保存し、GeoPackageのルートレイヤをQGISプロジェクトに追加します。

対応環境
QGIS 3.28以降とQGIS 4系を対象とします。プラグイン管理画面の互換範囲をQGIS 4系まで広げ、Qt・PyQGISの列挙型やフィールド型の差を吸収する互換処理を含めています。実際の起動・解析・出力は、使用するQGISの各バージョンで確認してください。

起点の選択
・起点レイヤ全体から1地点を指定できます。
・「選択した地物のみを使用する」は任意設定で、初期状態はオフです。最短距離ルートではオフの場合に起点リストの1地点、到達圏解析ではオフの場合に起点レイヤ内の全地点を使います。
・オンにする場合は、プラグイン画面を開く前にQGIS地図上で地物を選択します。選択中の各地物を起点として、指定した1つの目的地までルートを作成します。
・地図上で地物を選ぶには、QGISの選択ツールを使います。
・起点・目的地の候補リストには、レイヤの名称カラムを指定して表示できます。一般的な「name」「名称」等のカラムがあれば初期選択し、必要に応じて変更できます。

結果の保存
・保存先を1回指定すると、同じフォルダ・同じファイル名でCSVとGeoPackageを作成します（例：route_results.gpkgを指定するとroute_results.csvも作成）。
・CSVは1ルートにつき1行で出力します。複数起点を選んだ場合は、各ルートが別行になります。
・GeoPackageにはルート形状と速度の出典を含む属性を保存し、指定した名前でQGISに追加します。
・到達圏ラインは黒い縁取り付きのシアン系で表示します。起点別ライン・凸包は起点名ごとに色分けし、地物選択表示に近い黄色系を避けます。区間数が10万件以上の統合ラインは、初回描画の負荷を抑えるため非表示で追加します。必要に応じてレイヤパネルで表示できます。
・ルートレイヤは黒い縁取り付きのマゼンタ系の線で表示し、黄色の地物選択表示と区別しやすくしています。距離と参考所要時間をラベル表示します。距離は1,000 m未満ではm、1,000 m以上ではkmで表示します。時間は60分未満では分、60分以上では時間に換算して小数第1位まで表示します。文字には暗色バッファを付けています。
・到達圏解析では、区間CSV・GeoPackageに加えて「*_summary.csv」を作成します。個別モードでは施設別の行に到達道路延長、最小・平均・最大の道路上距離と参考時間を記録し、全体行に合計値と施設間の平均・中央値・最小・最大を記録します。統合モードでは全体の和集合と、出力区間を起点別に割り当てた内訳を記録します。内訳は施設単独の到達範囲を示しません。距離上限の解析では移動速度を使わないため、時間欄は空欄です。列名は日本語です。
・到達圏解析では、道路区間単位の全データをCSVとGeoPackage内の「*_区間明細」レイヤに保存します。区間明細レイヤはGeoPackage内に残りますが、プロジェクトには追加しません。QGISプロジェクトには集約ラインを追加し、区間数が多くても属性テーブルの行数を抑えます。
・個別モードでは、起点ごとに1地物のマルチライン集約レイヤを追加します。属性テーブルは起点数と同じ行数になり、到達区間数と到達道路延長を属性に持ちます。集約ラインと起点別凸包は起点名ごとにランダム風の色で分類し、色は同じ起点名であれば再実行後も同じになります。
・統合モードでは、QGIS表示レイヤを1地物にまとめ、起点名を「全起点を統合」と表示します。「origin_count」に起点数を記録し、「reachable_road_length_m」には、複数起点から届く道路区間の重複を除いた合計延長を記録します。この値は各施設の延長を足し合わせた値ではなく、起点からの距離でもありません。区間ごとの帰属や距離を確認する場合は区間明細CSV・GeoPackageを参照してください。
・集約ラインは黒い縁取りを保ち、都道府県全域を表示する縮尺でも線同士がつぶれにくいよう細めに表示します。統合ラインの地物数が10万件以上の場合は初期状態で非表示にし、必要な場合にレイヤパネルから表示します。設定画面は横幅を抑え、長いラベルや説明文を折り返して表示します。
・個別モードでは、起点ごとの道路到達区間の凸包を「*_起点別凸包」として出力し、これらを融合した範囲を「*_全起点凸包融合」として出力します。統合モードでは、統合到達区間を最短コストで帰属させた起点ごとの凸包を「*_到達道路別凸包」の1レイヤに出力します。これは起点単独の到達圏を表すものではありません。凸包は外縁を示す幾何学的な範囲であり、ポリゴン内部のすべてが道路網上で到達可能であることを意味しません。個別凸包の融合は各凸包の和集合で、全体を再度凸包化した範囲とは異なります。
・既存のCSVまたはGeoPackageがある場合は、日時を付けた別名で保存するため、既存結果は上書きしません。
・解析中は画面下部に道路読み込み、経路探索、保存の進捗ログを表示します。


保健師チーム巡回計画（試作）
・「複数チームで全訪問先を巡回」では、選択した1拠点から複数チームが出発し、訪問先を各チームへ割り当てて巡回順を作ります。各訪問先は必須として扱います。行動可能時間に収まらない訪問先は未割当として出力します。
・「時間内で対応人数・優先度を最大化」では、チーム数と行動可能時間を指定し、訪問先を選びます。対応人数カラムが必須です。「対応人数を最大化」は人数合計、「優先度を加味」は対応人数×優先度カラムの値を最大化する設定です。訪問先は全員を対応するか訪問しないかの二択で、部分対応は扱いません。
・起点レイヤで拠点を1地点選び、目的地レイヤで巡回先を指定します。起点はリストから選ぶ方法と、起点レイヤ上で地物を1つ選び「選択した地物のみを使用する」をオンにする方法を使えます。巡回計画は拠点1か所の設定です。選択した起点が複数の場合は、実行前に1地点だけ選ぶよう案内します。
・訪問先だけを選択対象にする場合は、目的地レイヤ上で対象を選んでから「選択した地物のみを訪問先にする」をオンにします。オフの場合はレイヤ内の全ポイントを使います。
・訪問先レイヤで、名称、対応対象人数、優先度、個別の対応時間カラムを選べます。対応時間カラムは任意で、初期設定では「全訪問先共通の対応時間（分）」に入力した値をすべての訪問先に適用します。個別カラムを選んだ場合はその値を使い、空欄には共通時間を適用します。数値カラムは数値型である必要があります。人数カラムを指定しない場合、全訪問先を1件=1単位として集計します。
・「対象者1人あたりの追加対応時間」を設定すると、訪問先の対応時間に人数×追加時間÷チーム人数を加算します。これはチーム人数に比例して同時対応できるという簡略化した仮定です。追加時間が0分の場合、チーム人数を変えても所要時間は変わりません。また、チーム人数だけでは最大対応人数などの要員制約を設定していません。休憩時間はチームごとの合計として勤務時間に加え、経路の中間にまとめて挿入します。
・移動距離行列は道路グラフ上の最短距離から作成し、選択した速度を一律適用します。初期構築と訪問先数に応じた最短経路探索を行うため、対象地点が多いと計算時間・メモリ使用量が増えます。多数地点で実行する前に、少数の選択地点で動作を確認してください。
・巡回順は挿入法と2-optを使う試作ヒューリスティックで作成します。全体最適を保証せず、全訪問モードで未割当が出ても、数学的に実行不可能と証明したことにはなりません。計算時間、結果の実行可能性、未割当地点を確認してください。
・全訪問モードで未訪問先が出た場合、出力前に「現在の設定で出力」「設定を自動調整」「キャンセル」を選べます。自動調整ではチーム数、チームごとの行動可能時間、全訪問先共通の対応時間を調整候補にし、どの項目を使うか、優先順位、チーム数・時間の上限、共通対応時間の下限を指定できます。優先項目が上限・下限まで達しても全訪問先を割り当てられない場合は、次の優先項目を調整します。
・1チームあたりの人数は自動調整しません。共通対応時間は訪問先ごとの対応時間カラムが未選択の場合に限り調整できます。自動調整は巡回計画を再計算し、探索した候補の中で未訪問数が最小の結果を出力します。全訪問できない場合は、調整結果を出力するか選択できます。
・自動調整は、チーム数は1チーム単位、行動可能時間は15分単位、共通対応時間は0.1分単位の候補値を試します。候補値の探索には単調性を仮定した二分探索を使います。表示する調整結果は検討した候補の範囲での結果であり、巡回計画自体も試作ヒューリスティックであるため、全体最適や実行不可能性の証明にはなりません。
・GeoPackageにはチーム別経路ラインと全巡回候補地点を出力します。地点レイヤの「status」で訪問予定と未訪問を区別できます。CSVには全候補の訪問順・到着予定（出発後の経過分）・対応量・未訪問理由、サマリーCSVにはチーム別の移動距離・移動時間・対応時間・休憩時間・勤務時間・訪問率・対応量カバー率を出力します。
・巡回計画では、サマリーCSV「*_summary.csv」と複数シートのExcel報告書「*_summary_report.xlsx」を作成します。Excelには「全体サマリー」「チーム別実績」「訪問先一覧」「未訪問先」「見方・注意点」の5シートを収録します。全体条件と調整前後の値、チームごとの距離・時間・訪問件数、訪問先ごとのチーム・順番・到着見込み、未訪問先の理由を確認できます。チーム別の移動距離・移動時間は、設定がオンの場合、拠点への帰着分を含みます。
・画面右上の「English」ボタンで画面表示を英語へ切り替えられます。英語表示で解析した場合、出力CSV、巡回計画のサマリーExcel、GeoPackage内の解析レイヤ名・説明値も英語で出力します。入力レイヤ名・地物名など利用者のデータに由来する値は原文を保持します。
・プラグインアイコンは白背景にシアンの道路網とアンバー色の地点マーカーを配したデザインです。
・訪問先の時間帯指定、複数拠点、日をまたぐ計画、訪問先間での部分的な人員配分は未対応です。一方通行、車両通行規制、実際の渋滞変動は反映しません。

道路グラフの読み込み範囲
・最短経路では起点と目的地の周辺だけを空間検索し、範囲外のライン部分を切り落としてグラフを作ります。範囲内の経路が範囲外を通る経路より短いと確認できるまで、検索範囲を段階的に広げます。
・到達圏では、設定した距離または所要時間と速度から必要な距離を算出し、起点周辺の道路だけをグラフ化します。起点のスナップ距離も範囲に加えます。
・実行ログに道路レイヤ全体の地物数、空間索引の有無、解析範囲でグラフ化した道路地物数・頂点数・区間数を表示します。道路レイヤに空間索引がない場合、データ形式によっては範囲内の道路を見つけるために全地物を走査することがありますが、グラフ構築には範囲内の道路のみを使います。
・起点が広範囲に分散している場合は、その起点群を含む範囲が広くなります。必要に応じて道路レイヤを地域別に切り出してください。

移動速度
・平時の歩行：一般成人1.30 m/s、高齢者参考値1.00 m/s。
・災害時の歩行：避難計画の標準目安1.00 m/s、歩行困難者等0.50 m/s、東日本大震災時の避難実態調査値（全体0.62、単独0.69、歩行困難な同行者あり0.52、健常者20～50歳代0.75、乳幼児・高齢者等の同行者あり0.46 m/s）。実態調査値は当該災害の状況に基づく値です。
・学童：足立区の通学距離計画値として、小学生0.67 m/s、中学生1.00 m/s。全国一律の実測平均ではありません。
・自転車：自由旅行速度16.8 km/h、公道での旅行速度9.6 km/h。
・自動車：国土交通省「令和3年度全国道路・街路交通情勢調査」の集計値から選択できます。速度統計の集計地域（都道府県・政令市等）、道路種別、朝夕混雑時／昼間非混雑時／昼間12時間平均、地域区分を指定します。地域は都道府県順に並べ、政令市等は該当する都道府県の後に表示します。選択中の時間帯・地域区分に公表値がある地域と道路種別だけを候補に表示します。道路種別は高速道路・一般国道・地方道などの分類を先頭に付けて表示します。
・過去に使った自動車30.0 km/hの概算設定も選べますが、官公庁の実測平均ではありません。
・任意速度はkm/hまたはm/sで入力でき、設定理由と出典URLを任意記録できます。
・速度シナリオの出典、速度、入力単位、根拠説明は画面に表示され、CSVとGeoPackageの属性に出力されます。

自動車速度の解釈
・統計の地域欄は、道路交通センサスの速度集計範囲（都道府県や政令市等）です。到達圏の地理的な解析範囲を指定したり、道路レイヤを切り抜いたりする機能ではありません。
・道路種別・地域区分・時間帯の選択値は、選択した集計条件の平均値です。現在の試作版ではその値を道路ネットワーク全区間に一律適用します。道路区間ごとの旅行速度、通行可能な道路種別、時間帯に応じた交通状態を再現するものではありません。
・調査の旅行速度は、秋季平日における方向別の調査値です。混雑時は朝（7～9時）または夕（17～19時）、昼間非混雑時は9～17時の集計です。時間帯別交通量による加重平均は昼間12時間の値です。
・国土交通省の公開ページに掲載された一般交通量調査結果を使用しています。令和3年度調査の公表CSVを同梱しており、CSVに含まれない地域・条件の値は選択できません。

インストール
1. QGISの「プラグイン」→「プラグインの管理とインストール」→「ZIPからインストール」を開きます。
2. GCHAM_Network_Analysis_0.4.11.zip を選択します。
3. プラグインを有効化し、プラグインメニュー直下またはツールバーの「G-CHAM Network Analysis」を開きます。

入力条件
・道路ネットワークはラインレイヤ。交差点はラインの頂点で分割・接続済みである必要があります。
・道路レイヤはメートル単位の投影座標系である必要があります。
・起点と目的地にはポイントレイヤを使用します。起点は1地点指定、または事前に地図上で選択した複数地点を指定できます。目的地は1地点を選びます。
・ポイントは道路頂点へスナップします。最大距離は画面で設定できます。
・「地点から道路までのずれを許す距離」は、地図上の地点から道路ラインの頂点（交差点・端点）までの距離の上限です。解析前に起点と目的地すべてを確認し、超過地点と全点を接続する最小距離を表示します。最小距離に自動変更して続けるか、解析を中止して手動で設定するか選べます。値を大きくしすぎると別の道路へ接続される可能性があります。

試作版の制限
・ラインの全区間を双方向通行として扱います。一方通行、歩行者・自転車・自動車の通行規制、階段、路面、勾配は判定しません。自動車速度を選んでも、自動車が通れない道路区間は除外されません。
・起終点は道路頂点へ直線スナップし、その直線区間も距離と表示に含めます。
・ライン同士の交差は、既に頂点として接続されている箇所だけ通行可能です。立体交差の判定はありません。
・公道での旅行速度は調査コースで信号待ちを含む値です。プラグインは距離÷速度で所要時間を算出し、信号待ちを追加しません。
・到達圏解析では、「選択した地物のみを使用する」がオンなら選択中の点だけ、オフなら起点レイヤ内の全点を使い、距離または移動速度による所要時間の上限を指定できます。道路網上で到達できる道路区間を部分区間も含めて出力します。
・「起点ごとに個別」は各起点の到達範囲を独立して計算し、重複区間も起点ごとに記録します。「全起点で統合」はいずれかの起点から到達できる道路区間の和集合を重複なく一度だけ出力します。個別方式の全体延長は重複を含む起点別延長の合計です。統合方式の起点別サマリーは、統合レイヤに記録した帰属先ごとの内訳であり、施設単独の到達範囲ではありません。起点別の比較には個別方式を使います。
・到達圏のCSVとGeoPackageは地物単位で逐次保存し、全区間をメモリにためません。道路グラフはコンパクトな隣接リストと空間索引で保持します。ルート解析では同じ目的地に向かう複数起点の最短路を一度だけ計算します。道路が非常に大きい場合は、PCメモリやQGISの処理能力により時間がかかることがあります。
・巡回計画は1拠点・1日・同一条件の複数チームを対象とする試作機能です。時間帯指定、複数拠点、資格別チーム、道路の一方通行・車両規制は扱いません。
